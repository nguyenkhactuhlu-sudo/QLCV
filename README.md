# QLCV - He thong Quan ly cong viec VKSND tinh

## Gioi thieu
He thong quan ly nhat ky cong tac va danh gia ket qua cong viec hang ngay
cho can bo, cong chuc, kiem sat vien VKSND tinh.

## Yeu cau he thong
- Node.js 20+
- npm 9+

## Cai dat
```bash
npm ci
```

## Chay development
```bash
npm run dev
```

## Build
```bash
npm run build
```

## Chay test
```bash
npm test
```

## Kien truc
Xem docs/requirements.md va docs/permission-matrix.md

## Moi truong
Copy .env.example thanh .env va dien cac gia tri phu hop

## Trien khai
- Frontend: Cloudflare Pages
- Database: Supabase
- CI/CD: GitHub Actions
